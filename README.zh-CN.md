# 工时表语法生成实验

本仓库是一个独立的本地实验，为 Payslate Online 的防御性健壮性测试生成合成工时表 CSV。仅使用 Python 3.12 标准库，不涉及网络服务。

```sh
python3 generate.py --seed 7 --count 3
python3 -m unittest discover -v
```

输出会标明每个文件的起止位置；这些标记仅用于展示，不属于 CSV 内容。调用 `derive("file", random.Random(seed), 8, covered)` 可得到单个文件的文本，编码为 UTF-8 后可保留可选的文件开头 BOM。相同种子和设置会生成相同的文件。

`grammar.json` 用列表保存每条规则的备选项，并通过 `<rule>` 引用其他规则。数据行数限定为一至五行（N = 5），修改对应备选项即可调整上限。`--depth` 默认为 8；推导达到深度上限时会明确报错。覆盖统计记录选中的 `(规则, 备选项索引)`，包括空字符串选项；它不代表组合覆盖率，也不代表产品代码覆盖率。

语法涵盖逗号、分号和制表符分隔，可选 BOM、LF/CRLF、表头别名及大小写变化、可选节假日字段、带引号字段、引号内的分隔符、双引号转义和空行。日期取自 2026 年 6 月至 7 月 12 日，均为有效日期。时间采用两种受支持的格式，包含跨夜班次，起止时间不会相同。每个文件只选择一次分隔符和换行符，并在推导过程中共享；可选列的表头与所有数据行也共享同一选择。

ADR 0003 要求拒绝未知表头。排班软件导出的文件常带备注、休息时长之类的列，因此语法也会加入可选的 `notes` 和 `break minutes` 列，用来探索这一边界：含有这些列的文件在 CSV 结构上有效，但不符合可接受的表头约定。空行不含字段，检查列数时会跳过。产品尚未决定是否支持引号内换行，因此本语法不生成这种情况。
